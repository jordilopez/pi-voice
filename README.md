# pi-voice

Voice commands and spoken feedback for **pi-coding-agent**, as a Pi package.

> ⚠️ **Platform support: tested on macOS only.** TTS uses macOS `say` and mic
capture uses ffmpeg's AVFoundation input — both are macOS-specific. Linux and
Windows are untested and will not work as-is (Linux would need `espeak`/`piper`
for TTS and `arecord` for capture; Windows would need its own equivalents).

- **In (commands):** push-to-talk dictation → speech-to-text → inserted into the editor.
- **Out (feedback):** when the agent finishes, it speaks **one short phrase summarizing the outcome** (e.g. "Tests now passing"), generated by the model — not the whole answer. Switch to `full` mode to speak the entire response, or `off` for silence.

## Requirements

- macOS (uses `say` / `afplay`; STT recording uses `ffmpeg` + AVFoundation).
- `ffmpeg` on `PATH` (`brew install ffmpeg`).
- A speech-to-text backend, one of:
  - **local:** [whisper.cpp](https://github.com/ggerganov/whisper.cpp) — install with:
    ```bash
    brew install whisper-cpp         # installs `whisper-cli` binary
    mkdir -p ~/.cache/whisper-cpp
    curl -L -o ~/.cache/whisper-cpp/ggml-base.en.bin \
      https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.en.bin
    ```
    The extension auto-detects `whisper-cli` / `whisper-cpp` on PATH and searches
    `~/.cache/whisper-cpp`, `/opt/homebrew/share/whisper-cpp/models`, and `$HOME`
    for a `ggml-*.bin` model. If yours is elsewhere, set its path in `src/index.ts` (`transcriber.whisperModel`).
  - **cloud:** an OpenAI API key in `OPENAI_API_KEY` (uses `whisper-1` via `/v1/audio/transcriptions`).
    **Privacy note:** this sends your recorded audio to OpenAI's servers for transcription. Use the local whisper.cpp backend if your recordings contain sensitive information.
- macOS **Microphone** permission for your terminal app (System Settings ▸ Privacy & Security ▸ Microphone). Without it, capture produces an empty file and you'll see a clear error.

## Install

### From a local checkout

```bash
# User-wide (all projects)
pi install /absolute/path/to/pi-voice

# Or project-local only
pi install -l ./pi-voice
```

Verify it registered:

```bash
pi list
```

Remove later with:

```bash
pi remove ../../development/pi-voice   # match the path shown by `pi list`
```

### During development

Use `-e` for a one-shot load without touching settings, and `/reload` inside a
session to pick up edits without restarting pi:

```bash
pi -e /absolute/path/to/pi-voice
```

After installing, restart pi (or run `/reload` in an active session) to load
the extension.

## Usage

| Trigger | What it does |
|--------|--------------|
| `Ctrl+Shift+V` | Start recording. Press again to stop and transcribe. |
| …end a phrase with **"copy"** | The trigger word is stripped and the rest is **sent straight to the model** (no Enter). |
| …no trigger word | Transcript drops into the **editor** for you to review/send. |
| `/speak <text>` | Speak arbitrary text (works even in `off` mode). |
| `/voice-stop` | Stop speech and cancel an in-progress recording. |
| `/voice-config` | Feedback mode, TTS voice, send catchphrase, summary model, STT backend. |

### Spoken cues
- **Turn finished:** a short model-generated headline of the outcome, e.g. *"voice feedback now working"*.
- **`ask_user` prompt raised:** says *"I've got a question about <topic>"*, where `<topic>` is a 2–6-word phrase condensed from the actual question. The announcement runs asynchronously so the prompt isn't blocked by the model call.

### Send catchphrase
By default the trigger word is **"copy"**. Say your phrase and finish with it:
> "run the test suite for me, *copy*" → sent immediately as: *run the test suite for me*

The word only fires when it's the **last word** (so "I am copying the file" is safe). Change it or disable auto-send via `/voice-config ▸ Send catchphrase` (blank = always drop in the editor).

## How it works

```
src/index.ts   extension entry: events, shortcut, commands
src/tts.ts     macOS `say` speech synthesis (cancellable)
src/stt.ts     ffmpeg AVFoundation capture + pluggable transcription
src/text.ts    pure text helpers (phrase truncation, catchphrase, sanitize)
```

- Outbound: `agent_settled` (not `agent_end`, which can fire more than once per turn) → in `cue` mode the model condenses the reply into one attention phrase (falls back to a few words if the model call is unavailable); short replies are spoken as-is; `full` mode speaks the truncated text.
- Questions: a `tool_call` for `ask_user` announces *"I've got a question about <topic>"* asynchronously.
- Inbound: `Key.ctrlShift("v")` toggles a spawned `ffmpeg` recording; on stop it transcribes via whisper.cpp. If the transcript ends with `dictation.catchphrase` (default "copy"), the word is stripped and `pi.sendUserMessage()` sends it to the model; otherwise `ctx.ui.setEditorText()` drops it in the editor.

## Configuration

Settings are persisted to **`~/.pi/agent/pi-voice.json`** and loaded at
`session_start`, so `/voice-config` choices survive restarts and `/reload`.
Delete the file to reset to defaults.

Code-level defaults (used on first run, or when the JSON file is absent):

- `speaker.mode` — `"cue"` (one short summary phrase, default), `"full"` (read the answer), or `"off"`.
- `speaker.summaryModel` — `"provider/model"` to use for the summary (defaults to the active model; point at a cheap/fast model to cut cost/latency).
- `speaker.shortReplyChars` — replies under this length are spoken verbatim (no model call). Default `60`.
- In `cue` mode the spoken phrase is always hard-capped at **5 words** (the summarizer is instructed to return a 3–5 word headline, and the result is word-truncated as a safety net).
- `speaker.voice` — any macOS `say` voice (`say -v '?'` to list).
- `speaker.rate` — words per minute.
- `recorder.audioDevice` — AVFoundation audio device index; find yours with:
  ```bash
  ffmpeg -f avfoundation -list_devices true -i ""
  ```
- `recorder.maxRecordMs` — safety cap so a forgotten recording can't run forever.
- `transcriber.kind` — `"whisper-cli"` or `"openai"`; auto-detected at session start.
- `dictation.catchphrase` — trailing word that auto-sends a dictation to the model. Default `"copy"`; set `""` to always drop in the editor.

## Notes / limitations

- **macOS-only.** See the disclaimer at the top — other platforms are untested and require backend swaps for both TTS and capture.
- Transcription happens only after you press stop; there's a short pause while the backend runs.
- Speech is truncated and cancelled when a new turn starts, so long answers don't pile up.

## Known limitations

- **`Ctrl+Shift+V` collision:** on some terminals (especially Linux), `Ctrl+Shift+V` is bound to paste. If this conflicts with your workflow, you can change the shortcut in `src/index.ts` (look for `Key.ctrlShift("v")`).
